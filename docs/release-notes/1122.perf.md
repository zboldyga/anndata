`import anndata` no longer imports the optional dependencies dask, xarray, awkward, cupy, and zappy. The corresponding classes in `anndata.compat` (e.g. `DaskArray`, `XDataset`, `CupyArray`) are now lazily resolved placeholders that work with `isinstance`, `issubclass`, and {func}`functools.singledispatch`, but are no longer identical to the real classes: use `isinstance` instead of `type(x) is DaskArray`, and import the real class to subclass it {user}`zboldyga`
