`import anndata` no longer imports the optional dependencies dask, xarray, awkward, cupy, and zappy. The corresponding classes in `anndata.compat` (e.g. `DaskArray`, `XDataset`, `CupyArray`) are now lazily resolved placeholders that work with `isinstance`, `issubclass`, and {func}`functools.singledispatch`, but are no longer identical to the real classes: use `isinstance` instead of `type(x) is DaskArray`, import the real class to subclass or pickle it, and be aware that `singledispatch` treats them like registered ABCs (an explicit base class such as `Mapping` registered on the same function takes precedence, and registering them next to another ABC or protocol that the real class also matches is ambiguous) {user}`zboldyga`
